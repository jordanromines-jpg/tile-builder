# Tile Steps

A web app for families who build with magnet tiles. A child opens it, picks a project from the Library (each
marked "You can build it!" or "Need 2 more" against the family's tiles), and builds it step by step from a 3D model
read aloud. A grown-up enters the tiles behind a grown-ups door. No profiles, no camera, nothing leaves the iPad.

The plans are in [`plans/`](plans/README.md), whose README says which is in progress. The first was
[`plans/2026-10-02-tile-builder.md`](plans/2026-10-02-tile-builder.md). This file used to hold an earlier plan, written before the research; everything in it was carried into that plan.
