# Tile Builder

A web app for kids aged 3 to 10 who build with magnet tiles. A parent enters the family's tiles once. Kids browse a
gallery of build projects, see which ones they can make with the tiles they have, and build them step by step in 3D.
Works offline on an iPad from the Home Screen, and keeps everything on the device.

Brands: Magna-Tiles, PicassoTiles, Connetix and generic 3-inch tiles.
